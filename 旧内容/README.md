# 旧内容归档

归档日期：2026-11-17。这里保留接手前的实现，以及本轮早期围绕旧版进行的修改、部署和审查资料。当前开发主线在根目录的 `runtime/`、`clients/`、`tools/world_builder/` 与 `worlds/`。

| 目录或文件 | 内容与用途 |
| --- | --- |
| 原C++与Qt项目/ | 原 C++ 核心、Qt 桌面端、测试、Schema、示例、旧素材、文档及发布脚本；包含本轮最初的侧栏调整，可参考，不继续承载新功能 |
| 历史游戏包/TaleState-0.2.0-win64/ | 下载的旧官方 Windows 游戏包 |
| 历史游戏包/TaleState-local/ | 本地编译、调整过侧栏的旧 Qt 游戏包 |
| 历史构建/ | 旧 build 目录、根 CMake 兼容入口等 |
| 历史审查/ | 旧项目审查结论与复现记录；其中路径按审查当时的目录书写 |
| 历史部署过程/ | 旧版下载、构建、打包脚本和日志、截图、下载分片及原发布 ZIP |
| 开发工具/ | 旧 Qt、构建用 Python、Ninja、依赖缓存、aqt 数据及安装包 |
| 原项目说明/ | 原安全说明和原旧版启动脚本的逐字备份 |
| 启动旧版.cmd | 已修正归档后路径，启动历史游戏包中的本地 Qt 版 |
| 归档清单.json | 每项原路径、新路径、文件数、字节数；单文件含 SHA256 |

归档迁移记录为 11,461 个文件、934,250,446 字节。移动目录前后核对文件数与总字节数，单文件核对 SHA256；这不是逐个目录文件的哈希验证。清单记录移动当时的状态，不包含后来新增的本说明和适配后的启动器。原启动脚本保存在 `原项目说明/原启动旧版.cmd`，因此清单中的启动器目标也指向该逐字备份。

双击本目录的 **启动旧版.cmd** 可打开旧 Qt 版。旧包可能保留原来的存档路径逻辑，游玩时会产生旧版数据。新旧存档不互通。

旧构建缓存和工具内可能仍含旧绝对路径，不能保证移动后直接增量构建。确需研究旧代码，应从 `原C++与Qt项目/` 重新配置一个构建目录，并自行指定匹配的工具链；已移入这里的根 CMake 兼容入口只供历史参考。

旧审查中的 `src/`、`apps/`、`tests/`、`docs/` 等原项目路径，主要对应 `原C++与Qt项目/` 下同名目录。历史文档保持原文，没有逐项重写里面的引用。

`.gitignore` 忽略本地大型游戏包、构建缓存、部署过程和开发工具；这些内容仍在本机，但不会随普通 Git 提交上传。旧源码与历史审查可纳入 Git。仓库 `.git/` 和许可证继续留在根目录，保持项目历史与授权可追溯。

完整修改历程、现有目录职责与后续开发入口见 [项目修改历程与目录说明](../项目修改历程与目录说明.md)。
