# 游戏界面调整（本地修改）

原先主窗口左侧同时放置世界工具、模型配置和引擎状态，游玩时需要频繁滚动寻找角色信息。
现在顶部「设置」打开独立窗口，包含模型 API、世界与存档、世界信息三个分页；主窗口侧栏用于角色状态，以及背包、已探索人物、旅途记录。

侧栏会在导入世界、创建角色、行动、推进时间、读取存档后刷新。人物名称来自世界包，只显示已探索人物；关系值来自引擎状态，不展示内部人物记忆。遇到 NPC 的判断采用引擎当前地点（包括日程导致的移动），不使用大模型叙述推断。

StoryState 增加 encountered_npcs；与其他状态一起原子提交，因此失败的行动不会产生虚假的探索记录。存档保存此字段，并验证人物 ID 与重复项。读取旧存档时，仅恢复当前在场或有交谈记录的人物，不假定全部人物都已探索。旧版本程序不能读取新存档。

修改集中于 apps/talestate-desktop/main.cpp、运行时和存档实现。新增侧栏流程检查及 NPC 探索/存档测试，并更新回放预期。验证时发现测试文件将 UTF-8 中文目录误当作本机代码页，因此测试路径统一使用 filesystem::u8path；HTTP 头测试按大小写不敏感比较，以兼容 Qt 6.8 的实际请求。

验证结果：Release 构建成功；87/87 项 CTest 通过；Windows 界面检查、打包后独立运行依赖检查通过。真实模型调用未测试。

本地运行：双击项目根目录「开始游戏.cmd」，启动 dist/TaleState-local/TaleState.exe。官方原版仍保留在 dist/TaleState-0.2.0-win64。详细使用方式见根目录「本地游玩说明.md」。
