# TaleState C++ v0.2.0 · 长期游玩测试版

这是面向长期游玩验证的 Windows 预发布版。玩家可以从世界设定表生成小型探索世界，创建角色，用自己的兼容模型 API 自由行动，并在同一世界里保存、继续游戏。

## 下载后怎么玩

1. 解压整个 `TaleState-0.2.0-win64.zip`，双击其中的 `TaleState.exe`。请保留压缩包中的文件夹和 DLL，不要只复制 exe。
2. 一键载入雾港示例，或填写世界设定表并生成探索世界包。生成的 `story.json` 请自行保留。
3. 创建角色，选择模型服务商，填写 API 地址、API Key 和模型名称，点击“测试连接”。模型调用由你的服务商计费；Key 不写入世界包或存档。
4. 在故事输入框描述行动。可探索、交谈、调查、拾取、使用物品、作出承诺、等待或睡眠，也可查看地点、背包、人物关系和当前状态。
5. 点击“保存进度”；重新打开时先加载同一世界包，再点“继续游戏”读取存档。

## 本版新增

- 世界生成时建立 2–4 个宽松的长期剧情方向，不预排固定的逐日剧情。
- 睡眠后或清醒跨日时，Agent 根据世界背景和已经提交的事实提出后续小事件；C++ 核对地点、人物和时间，到了时间才触发。
- 睡眠 4–12 小时。连续清醒超过 16 小时开始增加疲劳；疲劳达到 60 会生病并损失生命。睡眠降低疲劳。
- 疲劳、生命、生病状态及待发生事件进入存档，桌面界面显示这些状态。
- Agent 提出的无效跨日事件会被拒绝，不会提前改变游戏状态。

## 长期测试时请重点观察

- 连续玩多天、不同顺序调查与交谈时，人物回应是否承接已发生的事。
- 睡眠、熬夜、跳时间和读档后，日期、疲劳及事件是否一致。
- 每日小事件是否贴合玩家的选择；是否过早、重复或与地点人物矛盾。

## 当前边界

- 每日小事件目前是可观察的叙事变化，不能自行发放物品、修改关系或强制进入结局。
- 生成世界仍是小型探索开局，尚不能保证自动生成多年、持续扩张且始终合理的完整长篇剧情。
- 自由语言 Agent 需要用户提供兼容模型的 API 配置；不同服务商的生成效果和调用费用可能不同。
- 存档须与原世界包的 ID 和版本一致。Windows 未签名程序可能显示 SmartScreen 提示。
