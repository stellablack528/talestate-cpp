# 最小探索世界包规格（阶段一）

输入是一段世界观文字。桌面端会要求现有地图生成器恰好提出三个地点和连通路线，再生成开局目标、三件证据与 2–3 名 NPC。生成结果是正式 Story Package v1 JSON，可由 C++ 加载和校验。它用于探索、收集证据与追问，尚未实现结局生成。底层转换函数也能从较大的地图草案沿起点路线选取三个连通地点。

| 创作内容 | Story Package 字段 | 阶段一处理 |
|---|---|---|
| 世界标题和背景 | `title`、`world_context` | 地图标题和原世界观文字，加上当前目标 |
| 玩家起点与开场 | `entry`、起点场景的 `entry_node`、`nodes[].text` | 起点来自地图，模型生成开场与目标 |
| 三个地点 | `chapters[0].scenes` | 地图中从起点可达的三个地点 |
| 双向移动 | `agent_routes` | 每条选中地图路线展开为两个方向 |
| 2–3 名人物 | `agent_npcs` | 模型生成姓名、所在场景、可询问话题和答复 |
| 初始关系 | `agent_npcs[].initial_relationship` | -3 到 3；运行时初始化到权威状态 |
| 场景与证据 | `agent_objects`、`agent_objects[].item` | 每个地点有可观察环境与一件可观察、可拿取的证据；物品进入背包、对象从场景移除 |
| 证据追问 | `agent_npcs[].dialogue_rules` | 每位 NPC 绑定一件证据；`has_item` 检查玩家是否持有，成功后记录 NPC 记忆、增加关系，重复追问不会重复奖励 |
| 基础行动 | `agent_routes`、`agent_npcs[].dialogue_rules`、`agent_objects` | 移动、交谈、观察、拿取；证据和对话没有固定顺序 |
| 专门物品互动和两个结局 | `agent_item_rules`、终局 `nodes` | **后续阶段**补充，此阶段不声称有结局 |

生成包可在桌面端保存为 `story.json` 并立即加载。保存前会通过现有 Story Package 校验；校验失败时不会替换当前游戏。世界包 ID 从世界观、地图和实际生成的开局／证据／人物内容计算；即使输入同一段世界观，只要生成结果不同，存档也不会误载入另一份世界包。API Key 不会进入世界包。

新增证据规则后，生成包版本为 `0.2.0`。旧版 `0.1.0` 探索包的存档不会被当作新版存档读入。

当前验收是：两段不同世界观均能产出有效世界包；玩家能走访三个地点，以任意顺序观察和拿取证据；没有证据时追问会被拒绝，取得后可触发一次后续对话，并在存档恢复后保持证据状态。后续再扩展证据之间的组合、更多 NPC 反应和结局条件。
