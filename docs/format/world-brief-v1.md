# 世界设定草稿 v1

客户端使用可编辑表格收集世界观。预设条目是写作提示，不是必填项；玩家可以改名、删除或新增，最多 24 行。只有写了内容的行会进入模型请求，至少需要一行。不同条目的名称不能重复。

草稿使用 UTF-8 JSON，可以在客户端导出、再次导入。示例：

```json
{
  "format": "talestate.world-brief/v1",
  "fields": [
    {"name": "世界背景", "content": "海岸小镇的高中，每年举办灯塔奖学金评选。"},
    {"name": "世界规则与禁忌", "content": "保持现实校园题材，不出现魔法。"},
    {"name": "自由补充", "content": "玩家可以先交朋友，也可以先调查录音。"}
  ]
}
```

生成请求复用此 JSON，长度不超过 4000 UTF-8 字节。生成器把它当作玩家提供的世界数据；字段名帮助模型区分背景、偏好和规则，但不代替 C++ 对 Story Package 的结构和语义校验。草稿中不保存 API Key。生成后的 `story.json` 是单独的正式世界包，草稿不能直接当作世界包载入。
