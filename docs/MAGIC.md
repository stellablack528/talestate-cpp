# 法力、魔法老师与四元素战斗

revision6在当前村庄加入魔法老师伊莲娜（mage）。点她旁边“学习”可免费学会火花术、水箭术、冰霜术、雷光术，每课耗时10分钟；重复学习不扣时间或费用。也可通过正常对话明确提出学习，只有运行时实际产生spell_learned才算学会。老师不预知玩家的森林经历或其他人的私聊。

主角初始法力/上限50，基础法术强度8。伊莲娜出售学徒木法杖，4金币，装备后攻击+1、法术强度+5，与铁剑共用武器槽，不能叠加。马丁增加回血药水（恢复40血）和回蓝药水（恢复25法力），各2瓶、每瓶2金币；仍为独立物品库存，不自动复制补货。

## 操作

- 在战斗操作栏点“法术”查看已学法术和反应表，点击施放。法力不足按钮禁用，运行时也不扣资源。学会法术即可使用，法杖提供加成，不是强制施法门槛。
- 在背包日常杂物中点药水“使用”。战斗外耗时1分钟，战斗中占用一个完整回合，存活敌人随后反击；回复不超过上限。满血/满蓝不消耗药水。
- 每瓶药只能使用一次，正式consumed事件记录使用者、物品、资源、实际回复量和回复后的数值。consumed归属标记阻止重复转移/使用；读档与快照一同恢复物品状态。
- 睡觉后血量、法力回满，四只元素史莱姆重新刷新。已学习的法术与装备保留，已消耗药水不会重生。

## 四元素规则

参考[原神战斗模拟项目gcsim](https://github.com/genshinsim/gcsim)按动作、伤害、反应与增益分别记录的组织思路，本项目采用适配当前回合制的简化规则。下面倍率与持续时间是本项目的具体设定，不代表原游戏的完整规则。

| 施放元素 → 敌方元素 | 效果 |
| --- | --- |
| 水 → 火 | 蒸发，当前法术伤害×2 |
| 火 → 水 | 蒸发，当前法术伤害×1.5 |
| 火 → 冰 | 融化，当前法术伤害×2 |
| 冰 → 火 | 融化，当前法术伤害×1.5 |
| 水与冰任意方向 | 冻结，跳过当前反击；中间隔一回合才能再次冻结 |
| 水与雷任意方向 | 感电，额外4点伤害 |
| 火与雷任意方向 | 超载，额外6点伤害 |
| 冰与雷任意方向 | 超导，随后两回合物理伤害提高50% |
| 攻击史莱姆的原生同元素 | 伤害降到25%，最低1点 |

法术伤害先用“法术强度+法术power”替代原物理攻击值，进入既有防御公式，再乘反应倍率、向上取整并加反应附伤。当前无随机暴击、复杂元素量或持续掉血。史莱姆永久带原生元素；以后普通无原生元素敌人可以有暂时附着，发生反应后清除附着。

森林实例ID保留slime_1/2/3，分别改为火/水/冰，加slime_4雷；各20血/7攻/2防，击败各奖励2金币。保留旧档前三只的血量和击败状态，不为升级补发奖励；第一次睡觉后全部按新定义刷新。逃离保留怪物血量，清理本场临时冻结冷却与超导；战斗中存读档则完整保留回合与反应状态。

## 文件与接口

- runtime/talestate/magic.py：课程、消耗品、元素名称和反应表。
- combat.py：法力扣除、反应伤害、冻结/超导及药水回合。
- world.spells：id/name/element/mana_cost/power；NPC.lessons为法术ID→学费。
- items.consumable：resource为health/mana，amount正整数；items.bonuses新增magic_attack。
- state.learned_spells、人物mana/max_mana/magic_attack及消耗归属随session.json与快照保存。教学事件仅投影给实际授课老师。
- scripts/add_magic.py：根模板/生成器示例同步；显式--save升级原档及快照，先备份非媒体文件，不清空原进度。
