# 沉浸式界面与中世纪美术更新

按用户最新要求，任务栏隐藏所有 available 未接事项，仅按进行中/已完成分组，无任务留白。主场景不显示人物立绘或枚举人物的场景描述，只保留名字入口；立绘在角色窗口显示。对话移除任务按钮、独立对话说明、隔离机制说明和 AI 标签。

点人物可由模型主动开场，根据本人已知的请求或手头事务说话；同一次到访不会因反复开关重复请求开场。开场不代表玩家接受任务，未接事项仍不进入任务栏；正式接取、交付继续通过自然语言理解与真实事务提交。

输入区改为整块可点击的多行编辑区，显式管理窗口显示/关闭时的输入焦点；支持中文、粘贴、Enter 发送和 Shift+Enter 换行，API 失败保留草稿，各人物草稿隔离。移除等待时销毁输入控件的行为，避免回复后输入失去焦点。

界面采用暖灰墨色、米白字和黄铜线条。素材负责人通过三次 GPT Image 完成四背景、三人物中性与微笑整套欧洲中世纪重制。沿用地点/NPC/媒体稳定 ID，保留音频。所有运行图片在项目内，现有存档只复制 media；session.json、save.json、world.json 的 SHA256 前后一致，未清空或推进用户进度。

NPC 知情投影继续隔离：不读其他人物档案和私聊，不读作者 author_notes、全局物品/任务；时钟也仅传公开日期、时刻和昼夜，不传玩家住处及返家信息。角色的背景/关系改变仍只落当前人物、当前存档，API 失败不提交。

关键逻辑检查覆盖未接任务隐藏、主动开场不等于接取、角色修改及恢复、私聊不跨角色。真实 Ren'Py 渲染与程序内输入事件检查覆盖中文提交文本、Shift+Enter、Enter、错误保留草稿和切换人物；不能据此声称已验证所有 Windows 输入法。桌面交互辅助程序本轮报 trusted Node process exited unexpectedly，未据此绕过系统输入接口；输入验证在游戏测试过程中完成。

没有使用真实 Key 验证第三方模型输出质量。分发包随本轮实现重新打包，项目长期约定保存在 [项目注意事项](../项目注意事项.md) 与 AGENTS.md。
