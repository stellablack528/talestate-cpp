# 《霍格沃兹：缺刻之夜》素材

本支章使用内置 GPT Image 生成原创场景、人物和校园图。三次生成分别得到四景拼幅、三人透明拼幅和区域地图。拼幅按中线或等宽列裁成独立 PNG。

| 清单 ID | 内容 | 尺寸 |
| --- | --- | --- |
| `backgrounds.dorm`、`court`、`archive`、`tower` | 宿舍、露天观测课堂、校史档案室、原创观测星塔 | 836×470 |
| `portraits.tutor.neutral`、`student.neutral`、`archivist.neutral` | 艾琳、诺拉、奥斯温的中性立绘 | 512×1024，透明 |
| `maps.region` | 羊皮纸校园底图，庭院连接另外三个地点 | 1672×941 |

地图依设定坐标构图。图中建筑中心为手绘近似，精确地点、路线和名称由前端按世界数据叠加。
